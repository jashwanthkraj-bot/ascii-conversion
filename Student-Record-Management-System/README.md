# Student Record Management System

Mini Project – II for C Programming.

## Features

- Add a new student record using a singly linked list
- Automatically assign the smallest available positive roll number
- Delete by roll number or name
- Display all student records
- Modify by roll number, name, or percentage
- Save records to `student.dat`
- Load records automatically when the program starts
- Sort by name or percentage
- Delete all records
- Reverse the linked list
- Free dynamically allocated memory before exit
